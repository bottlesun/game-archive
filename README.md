# Game Archive

직접 만든 게임 프로젝트를 모아 소개하는 개인 게임 아카이브 사이트입니다.

## 예정된 화면

- **메인**: 슬롯머신 스타일의 비주얼과 오늘의 게임 추천
- **게임 목록**: 등록된 게임의 썸네일, 이름, 간단한 소개 표시
- **상세 이동**: 각 게임의 프로젝트 상세 페이지 또는 플레이 페이지로 연결

## 현재 등록 후보

- 서든어택: 라스트 라운드
- 오버워치 전략 시뮬레이터
- PROJECT ZERO

프로젝트 링크와 대표 이미지는 사이트 구현 단계에서 실제 배포 주소를 확인해 등록합니다.

## 디렉터리 구조

```text
game-archive/
├── README.md
├── AGENTS.md               # 프로젝트 작업 지침
├── .agents/skills/
│   └── game-archive-ui-consistency/
│       └── SKILL.md        # UI 구조와 공통 스타일 일관성 지침
├── index.html              # 사이트 진입점 (추후 작성)
├── assets/
│   └── images/              # 사이트 전용 썸네일 및 그래픽
├── css/
│   └── style.css            # 화면 스타일
├── js/
│   └── main.js              # 화면 동작 및 오늘의 게임 추천
└── data/
    └── games.json           # 게임 제목, 소개, 썸네일, 링크 정보
```

## 게임 데이터 초안

`data/games.json`에는 게임마다 다음 정보를 둡니다.

- `id`: 사이트에서 사용할 고유 키
- `title`: 게임 이름
- `genre`: 장르 또는 분류
- `description`: 짧은 소개
- `thumbnail`: `assets/images/` 기준 이미지 경로
- `url`: 상세 페이지 또는 플레이 페이지 주소
