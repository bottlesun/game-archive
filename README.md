# 게임 아카이브 — GAME ARCHIVE

직접 만든 게임을 한곳에서 소개하는 개인 게임 아카이브입니다. 시작 화면에서 오늘의 게임을 뽑거나 게임 진열장을 둘러볼 수 있습니다.

## 현재 기능

- 시작 화면에서 `YES`를 누르면 오늘의 게임 페이지, `NO`를 누르면 게임 진열장 페이지로 이동합니다.
- 첫 로비는 스크롤 없이 화면을 채우며, 방향키로 YES/NO를 선택하고 Enter로 이동할 수 있습니다.
- 오늘의 게임 페이지에서 슬롯이 회전하고 감속해 등록된 게임 중 하나를 추천합니다.
- 슬롯이 멈추면 같은 영역이 커지며 썸네일과 게임 소개를 표시합니다. YES로 게임을 실행하거나 NO로 다시 뽑을 수 있습니다.
- 게임 진열장은 아케이드 게임 메뉴처럼 왼쪽 목록에서 고르면 오른쪽에 큰 미리보기와 소개를 표시합니다. 클릭이나 방향키로 선택하고 Enter 또는 DETAILS로 상세 설명을 엽니다. 상세 화면 맨 아래 START GAME으로 실행하고 Esc 또는 BACK으로 목록에 돌아갑니다.
- 오늘의 게임 페이지에서 Enter로 슬롯을 돌릴 수 있으며, 서브페이지의 목록 화면에서 Esc를 누르면 로비로 돌아갑니다.
- 모든 페이지에 로비와 같은 어두운 보라색 배경, 주사선, 노랑·분홍 픽셀 타이틀을 적용합니다.
- 페이지에 진입하거나 브라우저 뒤로 가기로 돌아올 때 픽셀 로딩 바를 먼저 표시합니다. 페이지 제목과 선택된 게임에는 글리치 효과를 적용합니다.

## 등록된 게임

- 서든어택: 라스트 라운드 — 카드 심리전
- 오버워치 전략 시뮬레이터 — 전술 시뮬레이션
- 네온 서바이버 — 룰렛 전용 보너스 게임

## 프로젝트 구조

```text
game-archive/
├── .agents/skills/game-archive-ui-consistency/SKILL.md
├── AGENTS.md
├── README.md
├── index.html                 # YES / NO 시작 화면
├── today.html                 # 오늘의 게임 슬롯
├── games.html                 # 게임 진열장
├── history.html               # 제작자·의도·출처·Git 엔딩 크레딧
├── assets/images/             # 게임 썸네일
├── css/style.css              # 공통 디자인과 반응형 레이아웃
├── data/games.json            # 제목, 소개, 이미지, 프로젝트 링크
├── js/audio.js                # 합성 UI 효과음
└── js/main.js                 # 게임 목록 렌더링과 슬롯 선택 동작
```

## 로컬에서 열기

`fetch()`로 게임 데이터를 불러오므로 프로젝트 폴더에서 정적 HTTP 서버를 실행합니다.

```sh
python3 -m http.server 4181 --bind 127.0.0.1
```

그다음 브라우저에서 `http://127.0.0.1:4181/`을 엽니다.

새 게임을 등록할 때는 `data/games.json`에 항목을 추가하고 썸네일을 `assets/images/`에 넣습니다. UI를 수정할 때는 `.agents/skills/game-archive-ui-consistency/SKILL.md`의 공통 패턴과 스타일 기준을 따릅니다.

최초 배포일은 `data/games.json`의 `firstDeployedAt`에 `YYYY-MM-DD` 형식으로 등록합니다. 확인되지 않은 날짜는 `null`로 두며 상세 화면에서 숨깁니다.

현재 FIRST RELEASE 날짜는 Cloudflare 배포 설정이 main에 처음 반영된 PR 기준입니다(한국 시간). 실제 배포 성공 시각을 검증한 값은 아닙니다. 서든어택 PR #2: 2026-10-07, 오버워치 PR #6: 2026-10-04. 근거 PR과 커밋은 각 게임의 `releaseDateSource`에 보존합니다.

## 사운드와 히스토리

- 메뉴 선택·클릭·이동에 자체 합성 효과음을 적용하고, 우측 하단 소리 버튼의 음소거 설정을 저장합니다. 배경 음악은 사용하지 않습니다.
- HISTORY 페이지에 제작자, 제작 의도, 리소스 출처, GitHub 정보를 엔딩 크레딧으로 표시합니다. PAUSE / REPLAY를 지원하며 모션 줄이기 설정에서는 수동 스크롤로 표시합니다.
- 날짜의 PR 기준 설명은 화면에서 숨기고 근거 기록은 데이터에 유지합니다.

- 오늘의 게임 룰렛 회전에는 가속·감속에 맞춘 연속 효과음과 선택 완료 효과음을 적용합니다. 소리 OFF 설정을 따릅니다.

- 히스토리 크레딧이 한 번 끝나면 짧게 깜빡인 뒤 처음 위치에서 수동 스크롤로 전환됩니다. REPLAY로 자동 크레딧을 다시 볼 수 있습니다.


## GitHub Pages 배포

아카이브는 공개 저장소 `bottlesun/game-archive`의 GitHub Pages로 배포합니다. 개별 게임의 저장소와 Cloudflare 배포는 독립적으로 유지합니다.

- 사이트 주소: https://bottlesun.github.io/game-archive/
- Settings → Pages → Build and deployment → Source: GitHub Actions
- `main`에 사이트 변경을 푸시하면 `.github/workflows/pages.yml`이 자동 배포합니다. Actions에서 수동 실행할 수도 있습니다.
- 배포 대상은 HTML 5개와 `css/`, `js/`, `data/`, `assets/`입니다. 개발 지침·내부 인수인계 문서는 사이트에 포함하지 않습니다.
- 프로젝트 하위 경로 배포를 위해 내부 링크와 리소스는 상대 경로를 유지합니다.
- 로컬 인수인계 문서 `docs/monorepo-handoff.md`는 비공개 게임과 채팅 정보가 있어 공개 Git 추적에서 제외합니다.

## 네온 서바이버

`neon-survivor.html`에서 별도 서버나 외부 이미지 없이 실행되는 60초 탄막 생존 게임입니다. 게임 진열장에는 표시하지 않으며, 오늘의 게임 룰렛에서만 만나는 보너스 게임입니다. 세 게임의 선택 확률은 각각 1/3로 동일하고, 당첨 시 BONUS GAME! 표시와 전용 효과음이 나옵니다.

- 방향키·WASD, 마우스 또는 터치 드래그로 이동합니다. 기체 중심의 작은 점이 피격 판정입니다.
- 보호막 1회로 시작하며 보호막 아이템은 최대 2회, 감속 아이템은 4초 동안 탄을 느리게 합니다.
- 생존 1초당 100점, 아이템 250점, 60초 클리어 2,000점을 얻습니다. 최고 점수는 같은 브라우저에 저장합니다.
- START / Enter로 시작하고 PAUSE / Esc로 멈춥니다. RESUME / Enter로 재개하며 탭을 벗어나면 자동 정지합니다.
- 게임 코드 `js/neon-survivor.js`, 그래픽은 Canvas와 자체 SVG 썸네일로 구성합니다.
